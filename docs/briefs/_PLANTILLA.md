# Brief NN — Título

## Objetivo

Qué tiene que poder hacer la persona cuando el brief está listo. Una frase, o un párrafo corto.

## Rol(es) afectados

Quién lo usa. Si el rol todavía no filtra el menú, decirlo.

## Requisitos

1. Comportamiento concreto, comprobable en la pantalla.
2. Datos que se guardan y dónde.
3. Qué pasa en el caso vacío y en el error.

## Fuera de alcance

- Lo que parece vecino pero es otro brief.
- No adelantar backend, roles de menú ni la vista chofer si este brief no los nombra.

## Criterio de listo

- [ ] Se puede recorrer el flujo en el navegador.
- [ ] `npm run build` y `npm run lint` pasan.
- [ ] No quedó código muerto ni una feature que el brief no pidió.
